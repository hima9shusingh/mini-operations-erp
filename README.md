# Mini Operations ERP

## Overview
This is a Full-Stack Developer Technical Case Study for an Inventory and Work Order management system.

## Tech Stack
- **Frontend**: React, TypeScript, Vite
- **Backend**: Node.js, Express, TypeScript
- **Database**: PostgreSQL with Prisma (To be implemented)

## Setup

### Server
1. Navigate to the `server` directory.
2. Run `npm install`.
3. Run `npm run dev` to start the development server.
4. Run `npm run build` to build the TypeScript code.

### Client
1. Navigate to the `client` directory.
2. Run `npm install`.
3. Run `npm run dev` to start the client.
4. Run `npm run build` to create a production build.
